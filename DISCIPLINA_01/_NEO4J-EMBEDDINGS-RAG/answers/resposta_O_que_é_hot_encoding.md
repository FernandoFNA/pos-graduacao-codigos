O hot encoding é uma técnica utilizada em machine learning para representar dados categóricos de forma numérica. Nesse processo, cada categoria é transformada em um vetor binário, onde apenas uma posição é marcada como 1 (hot) e as demais como 0 (cold). Isso é útil para algoritmos de machine learning que lidam melhor com valores numéricos. Por exemplo, se tivermos as categorias "maçã", "banana" e "laranja", o hot encoding transformaria essas categorias em vetores binários como [1, 0, 0], [0, 1, 0] e [0, 0, 1], respectivamente. Essa técnica é comumente utilizada em tarefas de classificação.
